# Как сделать и подать игру

Инструкция для ученика: от готовой папки с игрой до публикации в каталоге.

Требования к самой игре (структура, `game.json`, ограничения) описаны в
[gamegenerateprompt.md](../gamegenerateprompt.md). Здесь — процесс подготовки
и подачи.

## Шаг 1. Сделайте игру

1. Скопируйте `games/_template/` → `games/<ваш-slug>/`.
2. Заполните `game.json`.
3. Напишите игру в `index.html`, `style.css`, `script.js`.

## Шаг 2. Проверьте игру локально

Откройте `games/<ваш-slug>/index.html` двойным кликом — игра должна
работать без сервера. Если играется с двойного клика — она заработает
и в каталоге.

Каталог крутится у вас локально? Можно проверить и «боевой» путь: поднять
сервер (`npm install && npm start`, откроется http://localhost:3000)
и пройти шаги 3–5 на нём — так вы увидите заявку глазами преподавателя.

## Шаг 3. Упакуйте папку в ZIP

Заархивировать нужно папку игры целиком (или её содержимое — сервер сам
разберётся, есть ли папка внутри архива).

- **Windows:** правый клик по папке игры → «Отправить» → «Сжатая ZIP-папка».
- **macOS:** правый клик по папке игры → «Сжать». macOS добавит в архив
  служебный мусор (`__MACOSX`, `.DS_Store`, `._файлы`) — не страшно,
  сервер вычищает его автоматически.

Размер архива — до 15 МБ. Если внутри архива несколько папок, сервер
ищет ту, в корне которой лежит `game.json`.

## Шаг 4. Подайте заявку

1. Откройте главную страницу каталога.
2. Нажмите **«Подать игру»**.
3. Приложите ZIP-архив.
4. Укажите slug. Поле можно оставить пустым — тогда сервер возьмёт slug
   из `game.json` внутри архива (или из имени папки в архиве).
5. Нажмите **«Отправить»**.

Проверка проходит мгновенно, прямо при отправке:

- **Зелёное сообщение** «Заявка отправлена преподавателю» — готово,
  переходите к шагу 5.
- **Красный список ошибок** — исправьте то, что он называет
  (расшифровка типовых ошибок — в конце
  [gamegenerateprompt.md](../gamegenerateprompt.md)), перепакуйте архив
  и подайте снова.

## Шаг 5. Что происходит дальше

Заявку проверяет преподаватель: открывает игру по кнопке «Открыть игру»
в админке, играет и решает судьбу заявки. Статуса заявки в реальном
времени нет — просто ждите.

- **Одобрено** — игра появится в каталоге на главной странице. Поздравляем!
- **Отклонено** — заявку удалят без публикации. Исправьте игру
  по замечаниям преподавателя и подайте заново с шага 3 — это обычная,
  не «штрафная» ситуация.

Пока заявка ждёт проверки, подать игру с тем же `slug` второй раз нельзя —
сервер ответит «Заявка уже ждёт проверки».

## Частые вопросы

**Подал(а) архив, а мне пишут «Игра уже существует».**
Игра с таким `slug` уже опубликована в каталоге. Придумайте другой `slug`
и переименуйте папку (и поле `slug` в `game.json`).

**Ошибка «Архив пуст или содержит только служебные файлы».**
В архиве не нашлось файлов игры. Проверьте, что заархивировали именно
папку с `index.html` внутри, а не пустую папку или только скриншоты.

**Можно ли положить в игру картинку с сайта?**
Нет. Внешние ссылки запрещены — все файлы должны лежать в папке игры.
Даже URL в комментарии в коде приведёт к отклонению архива.

**У меня игра работает, а при подаче «не проходит».**
Скорее всего, вы открывали её через локальный веб-сервер (Live Server и
т.п.), где работают абсолютные пути. Откройте `index.html` двойным
кликом — так, как будет проверять сервер.

**Где посмотреть, как выглядит моя заявка для преподавателя?**
Запустите каталог локально (`npm start`), подайте игру и откройте
http://localhost:3000/admin.
