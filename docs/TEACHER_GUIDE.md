# Гайд для преподавателя

## Модерация заявок

1. Откройте `/admin` (Basic Auth, логин-пароль выдаёт администратор сервера).
2. Для каждой заявки:
   - Нажмите «Открыть игру» — откроется игра в новой вкладке.
   - Поиграйте, проверьте содержание, управление, отсутствие ошибок.
   - Прочитайте `game.json` (если нужно — через превью файлов).
3. «Одобрить» — игра перемещается в `games/<slug>/` и появляется в каталоге.
4. «Отклонить» — заявка удаляется. При необходимости свяжитесь с учеником.

## Что проверять

- Игра запускается и управляется.
- Содержание уместно для школьного каталога.
- Нет внешних ссылок и посторонних запросов (валидатор уже отсекает, но проверьте глазами).
- Ассеты не нарушают авторские права.
- `game.json` заполнен и осмыслен.

## Снятие игры с публикации

Внизу админки — список «Опубликованные игры». Кнопка «Удалить» убирает
игру из каталога: удаляются и файлы игры, и её лайки (безвозвратно —
подтвердите осознанно). Ученик после этого может подать исправленную
версию с тем же `slug`.

## Откат вручную

Альтернатива кнопке «Удалить» — удалить папку `games/<slug>/` на сервере.
Игра исчезнет из каталога при следующей загрузке страницы. Лайки при
ручном удалении остаются в `data/votes.json` — при желании почистите
запись с этим `slug` вручную.
