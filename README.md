# Антология игр 🎄👾

Каталог учебных HTML/JS-игр в кибер-пиксель-новогоднем стиле.
Ученики разрабатывают игры локально, отправляют через кнопку «Подать игру»,
преподаватель проверяет и публикует.

## Быстрый старт (Docker, одна команда)

Нужен Docker с Compose. На сервере или локально:

```bash
cp .env.example .env        # заполнить ADMIN_PASSWORD и SESSION_SECRET
docker compose up -d --build
```

Готово:

- Каталог: `http://localhost:3000`
- Админка: `http://localhost:3000/admin` (пароль из `ADMIN_PASSWORD`)

Остановка: `docker compose down`. Логи: `docker compose logs -f`.
Обновление после `git pull`: снова `docker compose up -d --build`.

### Доступ из локальной сети

Каталог сразу доступен с других устройств по IP сервера:

1. Узнайте IP сервера: `ip addr` (Linux) или `ipconfig getifaddr en0` (macOS).
2. Откройте с любого устройства в той же сети: `http://<IP-сервера>:3000`.
3. Чтобы открыть порт 3000 в файрволе Linux: `sudo ufw allow 3000/tcp`.
4. Чтобы каталог работал без указания порта (просто `http://<IP>/`),
   задайте в `.env` `HOST_PORT=80`.

Сессии и лайки работают по HTTP: cookie помечается Secure только на HTTPS.

### Переменные окружения (`.env`)

| Переменная       | Назначение                                             |
|------------------|--------------------------------------------------------|
| `ADMIN_PASSWORD` | Пароль преподавателя (Basic Auth для `/admin`)         |
| `SESSION_SECRET` | Секрет подписи cookie лайков: `openssl rand -hex 32`   |
| `HOST_PORT`      | Порт на сервере (`80` — без указания порта в адресе)   |

`SESSION_SECRET` после запуска не меняют — иначе слетят все сессии и лайки.

## О проекте

«Антология игр» — каталог игр, созданных учениками учебного заведения.
Каждая игра — самостоятельный набор из `index.html`, `style.css`, `script.js`,
`game.json` и обложки, лежащий в папке `games/<slug>/`. Игра работает без
сервера — её можно открыть двойным кликом по `index.html` и сразу играть.

Сервер предоставляет каталог, лайки и модерацию. Никакой сборки и CI/CD:
игра попадает в каталог после ручного одобрения преподавателя.

## Структура проекта

    game-catalog/
    ├── index.html          — главная страница каталога
    ├── style.css           — стили (кибер-пиксель-новогодняя тема)
    ├── script.js           — рендер, лайки, модалка загрузки, снегопад
    ├── games/              — опубликованные игры
    │   ├── _template/      — шаблон для новой игры
    │   └── snake/          — демо-игра
    ├── _pending/           — заявки на модерации
    ├── admin/              — админка преподавателя
    ├── api/                — Express-бэкенд
    ├── data/               — лайки (создаётся при запуске)
    ├── deploy/             — альтернативный запуск без Docker (systemd + nginx)
    └── docs/               — документация

Игры (`games/`), заявки (`_pending/`) и лайки (`data/`) монтируются в
контейнер как тома — переживают пересоздание контейнера.

## Быстрый старт для ученика

1. Скопируйте папку `games/_template/` в `games/ваш-slug/`.
2. Отредактируйте `game.json`: `slug`, `title`, `summary`, `description`,
   `author`, `coverImage`, `createdAt` — обязательны.
3. Напишите игру в `index.html` + `style.css` + `script.js`.
4. Откройте `games/ваш-slug/index.html` — игра должна работать без сервера.
5. Упакуйте папку в ZIP.
6. На главной странице нажмите «Подать игру», заполните форму, приложите ZIP.

Подробности — в `gamegenerateprompt.md` и `docs/CONTRIBUTING.md`.

## Быстрый старт для преподавателя

1. Откройте `/admin` (пароль — `ADMIN_PASSWORD`).
2. Откройте игру кнопкой «Открыть игру», поиграйте, проверьте.
3. Нажмите «Одобрить» — игра появится в каталоге, — или «Отклонить».

Подробности — в `docs/TEACHER_GUIDE.md`.

## Как работает голосование

При первом визите сервер выдаёт анонимную сессию (cookie `antology_session`).
Одна сессия = один лайк на игру. Лайк ставится и снимается кнопкой ❤.
Счётчики хранятся в `data/votes.json`. Регистрации нет — осознанный
компромисс для школьного проекта.

## Запуск без Docker (для разработки)

```bash
npm install
ADMIN_PASSWORD=secret SESSION_SECRET=$(openssl rand -hex 32) npm run dev
```

Откройте http://localhost:3000 и http://localhost:3000/admin.

## Тесты

```bash
npm test
```

Встроенный раннер `node:test`, без дополнительных зависимостей. Юнит-тесты
валидатора и хранилища работают во временных каталогах; e2e поднимает
реальный сервер на случайном порту и проходит цикл «подача → одобрение →
лайк → удаление», не трогая данные проекта. Пути данных можно переопределять
переменными `ANTOLOGY_GAMES_DIR`, `ANTOLOGY_PENDING_DIR`, `ANTOLOGY_DATA_DIR`.
