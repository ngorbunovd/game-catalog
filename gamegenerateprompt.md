# Промпт: генерация папки с игрой

Файл-инструкция для создания новой игры. Подходит и человеку, и ИИ.

## Назначение

Если вы создаёте новую игру для «Антологии игр» — пройдите по этому
документу сверху вниз. В конце у вас должна получиться папка
`games/<slug>/`, готовая к отправке через кнопку «Подать игру».

Дальше по цепочке: упаковка и подача описаны в
[docs/CONTRIBUTING.md](docs/CONTRIBUTING.md).

## Пошаговый план

1. Скопируйте папку `games/_template/` в `games/<ваш-slug>/`.
2. Придумайте `slug` — имя папки и идентификатор игры (см. правила ниже).
3. Заполните `game.json` (шаблон и описание полей — ниже).
4. Нарисуйте обложку и сохраните её как `cover.svg` / `cover.png` / `cover.jpg`
   (путь к ней пропишите в `coverImage`).
5. Напишите игру в `index.html`, `style.css`, `script.js`.
   Ресурсы (картинки, звуки) кладите в `assets/` и подключайте относительными
   путями: `assets/hero.png`, а не `/assets/hero.png` — игра должна работать
   без сервера.
6. Откройте `games/<ваш-slug>/index.html` двойным кликом и играйте.
   Игра обязана работать без сервера — это и есть ваш тест.
7. Когда всё работает и чек-лист из конца документа закрыт — переходите
   к подаче: [docs/CONTRIBUTING.md](docs/CONTRIBUTING.md).

## Правила

- Только HTML, CSS и vanilla JavaScript. Без фреймворков, без сборки.
- Имя папки — `<slug>`, соответствует `^[a-z0-9][a-z0-9-]{1,40}$`
  (латиница, цифры, дефис; начинается с буквы или цифры; 2–41 символ).
- Обязательные файлы в корне папки: `index.html`, `style.css`,
  `script.js`, `game.json` и файл обложки (`cover.svg`, `.png`, `.jpg`
  или `.webp`).
- Дополнительно можно положить папку `assets/` для картинок, звуков, шрифтов.
- Размер папки — не более 10 МБ. Обложка — не более 500 КБ,
  рекомендуется не меньше 256×256.
- Запрещены любые внешние запросы: `fetch`, `XMLHttpRequest`, CDN,
  внешние шрифты, аналитика. Всё должно лежать локально.
  Важно: сервер отклоняет архив, если в любом `.html`/`.css`/`.js` файле
  встречается текст `http://` или `https://` — даже в комментарии.
  Ссылки на источники и благодарности пишите без схемы: «источник — wikipedia.org».
- Разрешённые расширения файлов: `.html .css .js .json .png .jpg .jpeg
  .webp .gif .svg .mp3 .ogg .wav .woff2 .txt .md`.
- Вызовы `eval()`, `new Function()` и `document.write()` игру не сломают,
  но преподаватель увидит предупреждение — лучше не использовать.
- Игра должна открываться двойным кликом по `index.html` и работать
  без сервера — это ваш собственный способ проверить её перед отправкой.

## Шаблон game.json

```json
{
  "slug": "my-game",
  "title": "Моя игра",
  "summary": "Одно предложение — что за игра",
  "description": "Полное описание в markdown: правила, идея, чем интересна.",
  "author": { "name": "Иванов Иван", "class": "7А" },
  "genre": "arcade",
  "tags": ["тег1", "тег2"],
  "controls": "Стрелки или WASD",
  "ageRating": "0+",
  "coverImage": "cover.svg",
  "language": "ru",
  "createdAt": "2025-11-19",
  "license": "CC-BY-4.0"
}
```

| Поле | Обязательное | Описание |
|------|--------------|----------|
| `slug` | да | Совпадает с именем папки, латиница/цифры/дефис |
| `title` | да | Название в каталоге |
| `summary` | да | Одна строка для карточки в каталоге |
| `description` | да | Полное описание: правила, идея, особенности |
| `author.name` | да | Имя и фамилия автора |
| `author.class` | да | Класс / группа автора |
| `coverImage` | да | Имя файла обложки в папке игры |
| `createdAt` | да | Дата в формате `ГГГГ-ММ-ДД` |
| `genre` | нет | Из списка: `arcade`, `puzzle`, `strategy`, `action`, `adventure`, `quiz`, `other` (по умолчанию `other`) |
| `ageRating` | нет | Из списка: `0+`, `6+`, `12+`, `16+`, `18+` (по умолчанию `0+`) |
| `tags` | нет | Массив тегов для поиска |
| `controls` | нет | Как управлять — показать в описании |
| `language` | нет | Язык игры, по умолчанию `ru` |
| `license` | нет | Лицензия контента игры, по умолчанию `CC-BY-4.0` |

## Что проверяет сервер перед публикацией

Архив проходит автоматическую проверку сразу при подаче. Заявка не
создастся, если:

- не хватает `index.html`, `style.css`, `script.js` или `game.json`;
- `game.json` — не валидный JSON или в нём нет обязательных полей;
- `slug` в `game.json` не совпадает с именем папки;
- `genre` или `ageRating` вне списков;
- в `author` нет `name` или `class`;
- файл обложки не найден, тяжелее 500 КБ или не `.png/.jpg/.jpeg/.webp/.svg`;
- в папке есть файлы с неразрешёнными расширениями;
- суммарный размер больше 10 МБ;
- в `.html`/`.css`/`.js` встречается `http://` или `https://`;
- игра с таким `slug` уже опубликована или уже ждёт проверки.

Со всеми ошибками сервер ответит списком сразу при отправке — исправьте
и подайте снова.

## Частые ошибки и как их исправить

| Ошибка сервера | Причина | Как исправить |
|----------------|---------|---------------|
| «Отсутствует обязательный файл» | В корне нет `index.html` / `style.css` / `script.js` / `game.json` | Проверьте, что упаковали папку игры, а не проект целиком |
| «slug ... не совпадает с именем папки» | Переименовали папку, но не `game.json` (или наоборот) | Сделайте одинаковыми |
| «Внешняя ссылка (http/https)» | Даже комментарий с URL в коде | Уберите схему из текста: пишите «site.ru», не «https://site.ru» |
| «Недопустимое расширение» | В архив попал `.psd`, `.ai`, `.zip`, `.bat` и т.п. | Уберите служебные файлы, разрешённые расширения — в правилах выше |
| «Размер игры превышает 10 МБ» | Тяжёлые картинки/звуки | Сожмите изображения (например, в `.webp`), обрежьте аудио |
| «Игра ... уже существует» | Такой `slug` опубликован | Придумайте другой `slug` и переименуйте папку |
| «Заявка ... уже ждёт проверки» | Такая игра уже подана и не рассмотрена | Дождитесь проверки или подайте с другим `slug` |
| «Архив пуст или содержит только служебные файлы» | Заархивировали мусор macOS/Windows | Заархивируйте папку игры (см. CONTRIBUTING.md) |

## Чек-лист перед отправкой

- [ ] Игра запускается двойным кликом по `index.html` — без сервера, без консоли ошибок
- [ ] Имя папки = `slug` в `game.json`, в формате латиница/цифры/дефис
- [ ] Все обязательные поля `game.json` заполнены, `author` содержит имя и класс
- [ ] Обложка ≤ 500 КБ, расширение `.svg` / `.png` / `.jpg` / `.jpeg` / `.webp`
- [ ] В коде нигде нет текста `http://` и `https://`
- [ ] Все файлы из списка разрешённых расширений
- [ ] Папка целиком ≤ 10 МБ
- [ ] Управление описано в `controls`, правила — в `description`
