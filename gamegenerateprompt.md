# Промпт: генерация папки с игрой

Файл-инструкция для создания новой игры. Подходит и человеку, и ИИ.

## Назначение

Если вы создаёте новую игру для «Антологии игр» — пройдите по этому
документу сверху вниз. В конце у вас должна получиться папка
`games/<slug>/`, готовая к отправке через кнопку «Подать игру».

## Правила

- Только HTML, CSS и vanilla JavaScript. Без фреймворков, без сборки.
- Имя папки — `<slug>`, соответствует `^[a-z0-9][a-z0-9-]{1,40}$`
  (латиница, цифры, дефис; начинается с буквы или цифры).
- Обязательные файлы в корне папки: `index.html`, `style.css`,
  `script.js`, `game.json` и файл обложки (`cover.svg`, `.png` или `.jpg`).
- Дополнительно можно положить папку `assets/` для картинок, звуков, шрифтов.
- Размер папки — не более 10 МБ. Обложка — не более 500 КБ, минимум 256×256.
- Запрещены любые внешние запросы: `fetch`, `XMLHttpRequest`, CDN,
  внешние шрифты, аналитика. Всё должно лежать локально.
- Разрешённые расширения: `.html .css .js .json .png .jpg .jpeg .webp
  .gif .svg .mp3 .ogg .wav .woff2 .txt .md`.
- Игра должна открываться двойным кликом по `index.html` и работать
  без сервера — это ваш собственный способ проверить её перед отправкой.

## Шаблон game.json

```json
{
  "slug": "my-game",
  "title": "Моя игра",
  "summary": "Одно предложение — что за игра",
  "description": "Полное описание в markdown: правила, идея, чем интересна.",
  "author": { "name": "Иванов Иван", "class": "7А" },
  "genre": "arcade",
  "tags": ["тег1", "тег2"],
  "controls": "Стрелки или WASD",
  "ageRating": "0+",
  "coverImage": "cover.svg",
  "language": "ru",
  "createdAt": "2025-11-19",
  "license": "CC-BY-4.0"
}
```

- Обязательные поля: slug, title, summary, description,
author.name, author.class, coverImage, createdAt.
- genre из: arcade, puzzle, strategy, action, adventure,
quiz, other.
- ageRating из: 0+, 6+, 12+, 16+, 18+.
- slug в game.json должен совпадать с именем папки.
